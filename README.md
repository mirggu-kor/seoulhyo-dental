## 사진 교체
각 회색 PHOTO 영역은 의도적인 자리표시자입니다. 실제 사진을 확보한 뒤 HTML의 `photo` 영역을 `<img>` 요소로 교체하고 CSS에서 비율을 조정하면 됩니다.
